Build my data scientist website with Flask

Recently, with my career moving to a next stage as a senior data scientist, I have this idea of doing freelancing projects besides my full-time job, to keep my tech skills up to date. And the first step i can think of is to have a fancy website, showcasing my projects and blogs.

In the meanwhile, I also want to have my projects and blogs on Medium without recreating the same contents. A better website idea come to my mind. Why not build a website that can point my audience to posts from my Medium account ?

Step 3. Flask it up!

Here is the fun part! If we want our website to pull Medium posts automatically, a static website with only HTML and CSS is not going to work. I still need a backend machine running behind our website to do the job.

As a data scientist, python is my go-to option to build a backend. I use flask to connect my static webpage.

You can refer to Flask documentation for more details.

Step 4. Web Scrapping

One thing I notice is that our Medium accounts have RSS feed data, and you can simply access it by [https://medium.com/feed/@<username>].

It is a XML format file containing links, pics and contents of our posts. It is pretty clear what the next step shall be. Web Scrapping!

I use BeautifulSoup to scrap my won RSS feed data. And here is the code i use:

def get_medium_publications(url):
    """
    Input: url - your Medium RSS Feed Url eg. https://medium.com/feed/@username
    Output: a list of dictionaries, each dictionary representing 1 article
    """
    r = requests.get(url)
    tree = ET.fromstring(r.content)

    out = []
    for item in tree.iter("item"):
        title = item.find("title").text
        link = item.find("link").text
        desc = BeautifulSoup(item.find('{http://purl.org/rss/1.0/modules/content/}encoded').text, "html.parser")
        imgurl = desc.find("img")["src"]
        summary = desc.find("p").text[:50] + "..."

        out.append({
            "post_title": title,
            "post_link": link,
            "imgurl": imgurl,
            "summary": summary,
        })

    return out

You can see I collect post_title, post_link, post_img url and post_summary of all my posts.
