1.Homogeneity test

H0: The two populations follow the same distribution.

2.Goodness of Fit Test.

Whether the observed data fit a certain distribution or not Example: Normality test

H0: The population fits the given distribution.

3.Independence test

Whether the observed data significantly differs from what is expected under the independence assumption

H0: The population fits the given distribution.

Both independence and goodness of fit test are calculating the deviation of observed value to an expected value. For the independence test, the expected value is derived from the expected independent probability. For the goodness of fit test, the expected value is derived from the expected distribution. For homogeneity test, the expected value is the other group of data.

4.Chi-Square test and the user cases

Pearson’s chi-squared test Pearson residuals measure the deviation between observed data a expected data. It is the standardized deviation of the cell.

It is slightly different from chi-square statistics. But they are measuring similar characteristic.

Requirement:

  • Simple random sample
  • Sample size should be large enough
  • Expected all cell count 5 or more, 80% of cells count 5 or more in larger tables, but no cells with zero expected count.
  • Independence of observation
  • categorical data

Fisher’s exact test(remedy for assumption 2,3)

If the sample size is small. But it can be applied to all sample size.<1000 The usual rule of thumb is that Fisher’s exact test is only necessary when one or more expected values are less than 5. Some alternative: Barnard test, Berger’s test [Not a standard practice]

Yates’s Chi-Square Test(remedy for assumption 2,3)[Seems not to be a good practice]

If the cell count assumption is not met.

Binomial test(exact test rather than approximation)

When there are only two categories. It is an exact test rather than an approximation(chi-square test)

Cochran-Mantel-Haenszel Chi-Squared Test(for stratified/matched categorical data)

When the data is stratified or matched categorical.

Mcnemar’s test(remedy for assumption 4)

If the observations are correlated
