# Comprehensive Guide to Chi-square Tests

A detailed exploration of different chi-square test variants, their applications, and implementations in statistical analysis.

## Introduction

Chi-square tests are a family of statistical hypothesis tests that are commonly used to determine whether there is a significant association between categorical variables. This guide covers the different variations of chi-square tests, when to use each one, and how to properly interpret the results.

## Types of Chi-square Tests

This guide covers three primary types of chi-square tests:

### 1. Chi-square Test of Independence

Used to determine if there is a significant relationship between two categorical variables. For example, testing if gender is associated with voting preference.

### 2. Chi-square Goodness of Fit Test

Used to determine if a sample data matches a population with a specific distribution. For example, testing if the distribution of blood types in a sample matches the expected distribution in the general population.

### 3. Chi-square Test of Homogeneity

Used to determine if different populations have the same distribution of a categorical variable. For example, testing if the proportion of smokers is the same across different age groups.
